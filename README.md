1. Project Overview & Objective
The school IT helpdesk receives a high volume of daily support requests from students and faculty covering network
connectivity, hardware failures, account access issues, and system performance bottlenecks. Currently, IT support
staff manually review every incoming ticket to identify the issue type, assign appropriate categories and
subcategories, and notify callers. This manual approach is time-consuming, prone to human error, and lacks
scalability. This project automates ticket classification and notification dispatch within ServiceNow using Flow
Designer by analyzing keywords in incoming incident descriptions.
