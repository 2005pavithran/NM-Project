## 🎯 1. Project Overview & Objective

> **The Challenge:** The school IT helpdesk receives a high volume of daily support requests from students and faculty covering **network connectivity**, **hardware failures**, **account access issues**, and **system performance bottlenecks**. Currently, IT support staff manually review every incoming ticket to identify issue types, assign categories, and notify callers—making the process time-consuming and prone to human error.

> **The Solution:** This project automates ticket classification and notification dispatch within ServiceNow using **Flow Designer** by parsing keywords inside incoming incident descriptions.

---

## ✨ 2. Key Features & Functionality

* 🔍 **Automated Keyword Extraction:** Scans incoming incident descriptions for specific keywords related to network, hardware, account, and performance issues.
* ⚡ **Dynamic Category Assignment:** Automatically updates the category and subcategory fields in ServiceNow based on matched criteria.
* 📨 **Automated Notifications:** Dispatches instant confirmation and status update notifications to callers without manual intervention.
* 📈 **Improved Efficiency:** Dramatically reduces ticket resolution time and eliminates human routing errors.
